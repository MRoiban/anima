Available event fields: x (number), y (number), dx (number), dy (number), startX (number), startY (number), pointerId (number), button (number), value (number), pressed (bool), index (number), control (number), deltaX (number), deltaY (number), text-index (number), pointer-x (number), pointer-y (number), pointer-delta-x (number), pointer-delta-y (number), key-pressed (string). Missing fields leave inputs unchanged. x/y use target parent coordinates; align="preserve" retains the grab offset. Example: write='{"x":"dragX"}'.

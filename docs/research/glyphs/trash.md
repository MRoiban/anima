# Trash: CLI-only AniML authoring test

Date: 2026-11-05. Base: `61655d2`. Author: implementation agent.
Time spent: approximately 15 minutes including installation, experiments, reporting and checks
(estimated wall time; no per-command stopwatch). Scope: `examples/trash.*` and this report.

## Result and design

Brief: **6/6**: hover lift, click open/shake/settle, press, reduced motion, a11y declaration,
and exact rest parity. `trash.animl` builds to `trash.ani`; `trash-ring.png` is a ten-frame,
one-second contact sheet generated by the CLI. No runtime code or dependencies changed.

The lid hinges at its right end, `16.195 6.496`. Hover rotates it clockwise 6 degrees
and lifts it 0.35 units over 0.16 seconds. Click opens it to 18 degrees, shakes the can
between -3 and +3 degrees and squashes it to `scaleX=1.04`, `scaleY=0.94`, then closes
by 0.9 seconds. The opening is intentionally modest to retain the source's 20×20 viewBox
and exact raster framing. Press scales the whole icon to 0.94 about `10 10`.
After a click the lid stays closed while hovered; leaving permits another hover lift.
Repeated clicks after settlement work. Clicks during the one-shot are intentionally ignored.

`a11y` declares `role="button" label="Empty trash" activate="empty" held="down"`.
`empty` is a declared trigger used by both the click listener and the rest/hover/closed
transitions. Keyboard/assistive-technology interaction for this particular icon was not
manually exercised in a browser; this authoring test uses the CLI as requested.

Reduced-motion hover/press use `skip`, freezing at identity; closing/click/release use `end`,
jumping to rest. CLI samples verify all three reduced-motion interactions settle at rest.
Changing motion preferences during an already-running timeline was not tested: the served
spec says the setting affects states entered from now on.

## Geometry investigation and least-bad workaround

`anima new trash --glyph fixtures/glyphs/trash.svg -o examples/trash.animl` reported:

```text
wrote examples/trash.animl (5 subpaths; see them with: anima inspect examples/trash.animl)
```

The initial inspect node was `glyph (path trash[all])`. Temporary copies with
`subpaths="0"`, `"1"`, `"2"` were rendered separately with `anima render`:

- 0: combined solid lid/handle/can exterior, not an independent lid.
- 1: handle hole.
- 2: can interior hole.
- 3 and 4: internal vertical bars (identified from their path coordinates).

The outer contour joins lid to body at `y=6.496`. I split its text at `L4.644 6.496`,
closed the lid across to `15.348 6.496`, and created a can exterior starting at
`15.348 6.496` through `4.644 6.496` and the original remaining contour. The handle
hole accompanies the lid; the can hole and bars accompany the body, with even-odd fill.
All original curve coordinates are retained. New glyph hashes describe the new strings;
the original glyph and its scaffold hash are also retained verbatim.

Separate fills produce antialiasing differences along their shared seam even with matching
geometry. To satisfy exact rest parity, the original compound path is visible at rest;
the split parts are visible only during motion. Boolean visibility tracks exchange them.
The hover track retains the original at time zero and swaps at `0.000001` seconds, so
reduced-motion `skip` retains the exact rest path. Click/close swap back at their final key.
This duplicates path data and adds bookkeeping, but avoids changing the source drawing,
introducing a runtime feature or sacrificing rest parity.

This decision follows the filled-outline / even-odd hole conventions in
[Glyphy compatibility research](../glyphy-compat.md), sections 2.1 and 3, and the served
authoring guide's instruction to keep holes with their contours. No Rive source, CLI docs,
commands or `.riv` files were used. No `packages/*/src` file was read to learn the format.

## Friction log

All commands below abbreviate `node packages/cli/src/main.ts` as `anima`.
“No diagnostic” means no CLI error/warning was printed, rather than a missing transcription.

1. **Workspace dependencies absent.** Command: `anima docs`. Expected: guide.
   Actual: exit 1; exact relevant Node diagnostic:

   ```text
   Error [ERR_MODULE_NOT_FOUND]: Cannot find package '@anima-format/core' imported from /home/jarvis/.t3/worktrees/anima/t3-a4c9ae5b/packages/cli/src/cli.ts
   ```

   `npm ci` resolved it (152 packages installed). Installation reported
   `10 moderate severity vulnerabilities` and an esbuild install-script warning.
   No dependency updates or audit fixes were attempted.

2. **Inspect does not expose the advertised subpaths.** Commands: `anima new ...` above,
   then `anima inspect examples/trash.animl`. Expected: five subpaths, indices and bounds
   to help find the lid, because the scaffold explicitly suggests inspect. Actual node:
   `glyph (path trash[all])`; no subpath list/bounds. No diagnostic. Worked around with
   temporary per-subpath markup and `anima render /tmp/trash-part-N.animl -o ...png`.

3. **Subpaths do not correspond to semantic parts.** Commands: per-subpath renders above.
   Expected: select a lid contour plus its hole using `subpaths`. Actual: subpath 0 joins
   lid and body; selecting only the handle hole renders a solid patch, not a lid.
   No diagnostic. Manual path surgery was required; the docs adequately explain
   subpaths but provide no workflow for separating a connected contour.

4. **Geometric splitting fails exact pixel parity.** Command:
   `anima render examples/trash.animl -o /tmp/trash-split.svg --current '#000000'`, followed
   by Resvg RGBA comparison with the fixture. Expected: equal pixels at identity.
   Actual differing RGBA channel counts at 20/40/256/640 px: **4/0/28/67**, maximum
   absolute channel difference **48**. No diagnostic. This is the rejected split-only
   version, before adding the original rest path. Workaround: original at rest, split
   parts only in motion, as explained above.

5. **Implicit render colour confounds source comparison.** Command: the same render
   without `--current`. Expected: inherited `currentColor` matching source's SVG default
   black. Actual: rendered root `color="#141413"`. At 256 px this inflated the split-only
   comparison to 32,674 differing channels. No diagnostic. `--current '#000000'` makes
   comparisons fair. The default is sensible for previews but needs parity guidance.

6. **Large lid motion clips silently.** Command:
   `anima render examples/trash.animl -o examples/trash-ring.png --sheet 10 --over 1 -e 'fire empty' --size 160`
   with the first 38-degree/-0.7-unit click draft. Expected: whole lid visible.
   Actual: handle clipped at the top of multiple cells. No diagnostic. The guide explains
   enlarging viewBox for bleed, but that changes same-size source comparison framing.
   Reduced click opening to 18 degrees/-0.1 units; inspected the regenerated sheet.

7. **Formatter does not expand inline keyframes.** Command:
   `anima fmt examples/trash.animl --write`, followed by `--check`. Expected from the served
   markup spec's “tracks one keyframe per line”: expanded/aligned keys. Actual: semicolon
   keyframes remain inline, and `--check` says `examples/trash.animl: formatted`.
   No error diagnostic. Kept this accepted canonical representation; no manual formatter fix.

Author-script error, separate from tooling friction: my temporary Python editor initially
matched `grid="20"` using a loose `d="..."` regex and raised `IndexError: list index out of range`.
It made no edit; validation still passed on the scaffold. Requiring a word boundary fixed it.
This was an author error, not an AniML diagnostic.

## Top three fixes, ranked

1. Provide a contour-splitting workflow for connected Glyphy parts, with rest-parity checking
   and clear handling of shared-edge antialiasing. Merely exposing subpath selection cannot
   animate this real glyph's lid independently.
2. Make `inspect` show subpath indices, bounds and hashes, ideally a labelled render atlas.
   Change the scaffold's suggestion until inspect actually provides this information.
3. Add a source-SVG parity command documenting colour and viewport normalization, reporting
   differing pixels/channels. Include frame bounds/clipping in sheet diagnostics so authors
   can choose bleed versus motion limits with evidence.

## Reproduce the authoring loop

```sh
node packages/cli/src/main.ts docs
node packages/cli/src/main.ts docs markup
node packages/cli/src/main.ts docs spec
# Initial scaffold only; do not overwrite the finished file:
node packages/cli/src/main.ts new trash --glyph fixtures/glyphs/trash.svg -o /tmp/trash.animl
node packages/cli/src/main.ts validate examples/trash.animl
node packages/cli/src/main.ts inspect examples/trash.animl
node packages/cli/src/main.ts fmt examples/trash.animl --check
node packages/cli/src/main.ts build examples/trash.animl -o examples/trash.ani
node tools/build-animl.ts --check
node packages/cli/src/main.ts render examples/trash.animl -o examples/trash-ring.png --sheet 10 --over 1 -e 'fire empty' --size 160
```

Edits were text authoring with Python, not a GUI or runtime API. All format discovery,
validation, sampling, rendering and compilation went through the CLI and its docs.
Resvg was used independently only to compare source SVG pixels with CLI-produced SVG;
no package source or player/render API was imported.

## Rest pixel comparison

```sh
node packages/cli/src/main.ts render examples/trash.animl -o /tmp/trash-rest.svg --current '#000000'
node packages/cli/src/main.ts render examples/trash.animl -o /tmp/trash-settled.svg --current '#000000' -e 'fire empty; advance 0; advance 1'
node packages/cli/src/main.ts render examples/trash.animl -o /tmp/trash-reduced.svg --current '#000000' -e 'motion reduce; pointer move 10 10; advance 0; fire empty; advance 0'
node --input-type=module <<'JS'
import { Resvg } from '@resvg/resvg-js';
import { readFileSync } from 'node:fs';
import assert from 'node:assert/strict';
for (const state of ['rest', 'settled', 'reduced']) {
  for (const size of [20, 40, 256, 640]) {
    const pixels = (file) => new Resvg(readFileSync(file, 'utf8'), {
      fitTo: { mode: 'width', value: size },
    }).render().pixels;
    assert.deepEqual(pixels('fixtures/glyphs/trash.svg'), pixels(`/tmp/trash-${state}.svg`));
    console.log(state, size, 'RGBA identical');
  }
}
JS
```

Result: **12/12 byte-identical comparisons**, zero differing channels; original viewBox retained.
SVG serialization itself differs because the CLI adds retained transform groups and explicit paint.

# P6 parity closure
P6 (text on the browser) audited: **66 of 84 rows done in P6**; **18 planned rows move to P7** as listed carry-overs (decided by the orchestrator, owner may revisit). In scope: **804/886 done (91 %)**, up from 738/886 (83 %) at the end of P3c. Total: 804/1238.
Evidence rule (as in `docs/parity/P3c-closure.md`): implementation plus tests and conformance, and a completed native comparison (strict oracle, budgets from measured anti-aliasing only), an evidenced skip where no faithful native counterpart exists, or a documented intentional difference. Native comparisons use the project's own generated fonts (`fixtures/fonts/anima-test.ttf`, `tests/oracle/text-opentype-features/rive/feature-fixture.ttf`); no third-party font enters the repository. Strict oracle at closure: 309 cases, exit 0.
Intentional differences recorded in the spec: inferred accessible names from text (native captures give empty labels), explicit leading in native comparisons (baseline translation documented), DOM-only text-input behaviour (IME, clipboard, mobile keyboard, native field semantics) closed with evidenced skips and both-engine browser tests.

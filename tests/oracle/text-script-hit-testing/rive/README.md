parity row's native methods belong to the scripting API; Anima explicitly excludes a script VM.

listener input conformance case, and real pointer/host/semantic behavior in Chromium and Firefox.

portion. See modules/a11y/TEXT.md and modules/a11y/P6-7-REPORT.md.

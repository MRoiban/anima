# Native comparison limitation

The local schema command for Text exposes no authorable direction field.
The inventory refers to derived runtime direction queries. Anima's explicit ltr/rtl override
is a browser direction attribute, while per-cluster drawing stays in logical order. A native
Latin text control would therefore not exercise the same forced-direction input. Do not label
it an equivalent oracle. Native HTML direction is covered by both-engine browser tests.
P6-9a accepts this no-faithful-authored-counterpart disposition; see ../skip.json and the
recorded property-name observation. Scripting queries remain won't-do.

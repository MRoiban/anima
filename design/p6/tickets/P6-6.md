## Ticket P6-6 — text input (heavy, DOM-backed) and its accessibility

Owns: new module `modules/text-input/**` (runtime entry `text-input`, **heavy**, budget 4,096 B per design §2; its markup in its own authoring entry), `modules/a11y/core/commands.ts` (headless tooling only, for script `type`/`compose`/`select` and semantic snapshots of fields), their tests. Not `packages/markup/src/**` (P6-4a), not `modules/text/**` (P6-4; read its exports), not `modules/a11y*/web/**` or a11y runtime core (P6-7 later).

Rows: text.input-text text.input-editable text.input-cursor text.input-selection text.input-selection-rounding text.input-focus-selection text.input-ime text.input-clipboard text.input-limits text.input-multiline text.input-obscured text.input-placeholder host-api.text-input host-api.clipboard-text input.text-listener input.write-text a11y.role-text-field a11y.state-multiline a11y.state-obscured a11y.text-proxy.

Design §7: a native `<input>` (single line) / `<textarea>` (multiline) sits transparently over the text box, focused through the focus module; the browser handles typing, IME, dead keys, clipboard, selection and the mobile keyboard. Anima draws text, caret and selection from the field's value and `selectionStart/End` (styled caret and selection drawables, rounded selection), placeholder and obscured masking; limits via `maxlength` plus a line limit; committed text writes to data (`input.write-text`) and fires `on="text"` listeners; `select-on-focus`. Semantics: the native field is the text-field element (multiline, obscured), mirrored into the semantic tree. Headless: script `type "<text>"`, `compose "<text>"`, `select <a> <b>`. Respect BF-2/BF-5 policies (overlay elements pass pointer input to the drawing except the field itself while editing; never stopPropagation). The P6 benchmark ("search card") needs: a search field with placeholder, typing that filters a list of five data-bound labels, a result count bound to data, accessible field — make that expressible in AniML in a few lines and add it as the module example, proven with the CLI's typing and accessibility commands.

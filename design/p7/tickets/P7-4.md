Repo: Anima, an open animation format (`.ani`, AniML `.animl`) and a small web runtime (`<anima-icon>`): a smaller, agent-native Rive for animated web UI. Your checkout is a worktree on a branch made from `p7` (see `git log -1`). Read first: `AGENTS.md` (incl. `## Repo rules`), `WORKLOG.md` (the orchestrator's memory: current state, owner decisions, gotchas), `design/p7/DESIGN.md` (the decided P7 design; your ticket is part of it), `docs/PLAN.md` "Definition of done" for a capability, and `docs/parity/P6-closure.md`.

## Ticket P7-4 — animated reflow, and the two layout integrations

Owns: `modules/layout/**` (incl. a new optional runtime entry `layout-reflow`, budget 1,024 B), the `fit="layout"` seam in `modules/host-fit/**`, their tests, conformance and oracle cases. Not `modules/text/**` (P7-6 is editing it; read its exports), not `modules/data-artboard/**` (P7-7).

Rows: layout.animated-reflow host-api.fit-layout.

1. **Animated reflow** (design §4): when a box changes, the drawn box moves from the previous drawn box to the new one over the `reflow` duration with its ease (existing ease vocabulary; inherited from the container, per-child override); retargeting mid-flight starts from the current drawn box (no snap); reduced motion snaps; `player.layoutBox(id)` keeps reporting the target box, and a documented way to read the drawn box exists for tests and hosts. Conformance cases sample mid-animation (start, middle, retarget); browser test in both engines. This is the design case of the P7 benchmark: a button whose background hugs a data-bound label and animates as the label grows.
2. **Text measurement:** P7-1 merged `measureText(player, nodeId, maxWidth?)` from the text module; replace P7-2's fallback adapter (`seam(P7-2)` in `modules/layout/**`) with it, so text participants hug their measured text and wrap within fill widths. Tests with the generated test font.
3. **`fit="layout"`:** P7-3's host-fit sets `player.layoutSize = [w, h]` (host size in px) and expects the root layout to reflow to it (see `modules/host-fit/P7-3-REPORT.md` and its stub test in `modules/host-fit/test/web/fit.test.ts`). Make the layout module honour `layoutSize` (converted to grid units) for the root container, replace the stub test with a real one in both engines, and close `host-api.fit-layout` when it meets the definition of done.

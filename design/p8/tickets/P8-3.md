## Ticket P8-3 — path following and spreading (internal path measurement)

Owns: new module `modules/pathfollow/**` (runtime entry `pathfollow`, `heavy: true`, budget 1,280 B),
its wiring, the `## pathfollow` chapter in `spec/SPEC.md`, conformance
`spec/conformance/rigging-{follow-path,list-follow-path}/`, oracle probes for both rows, inventory
status for these rows. Read-only: `modules/rig/**`, `modules/lists/**`, `packages/core/src/**` (reuse
the outline length code; a seam export if needed, marked).

Rows: rigging.follow-path rigging.list-follow-path.

Depends on: P8-1 merged into `p8-rigging`.

Implement `alongPath` and `spreadAlongPath` of DESIGN §3 through `registerConstraint`:
- Measurement is private (D20): flatten the target's current resolved local outline (`path` incl.
  morphs, `contour`, `circle`, `rect`, `arc`) with the SPEC "Shared outline lengths" subdivision into
  a cumulative-length table cached per geometry revision; point and tangent at a fraction; the
  target's world transform applies. Nothing is exported from the package.
- `alongPath`: `at` (open paths clamp 0..1, closed wrap; D19), `orient` (world rotation = tangent
  angle, 0° along +x), `offset` (the node's own translation away from rest is added after placing),
  `strength`. The path and the constrained node: path is a dependency (`targets()`).
- `spreadAlongPath`: places the node's direct children — a `repeat`'s items included — child k of n at
  `start + (end − start)·k/max(n − 1, 1) + shift` (D19), `orient` per child, `strength`. Children are
  the solved nodes (`writes()`); a changing item count re-places without re-solving order.
- Diagnostics: `rig-path-target` (target not a measurable shape). One test.
- A skinned target is measured from its undeformed outline: document it as a limitation in the spec.
- Example pair `modules/pathfollow/examples/orbit.animl` + `.ani` (a dot riding a curve with orient,
  and five beads spread along an arc).

Acceptance:
- `npm run test:scope -- pathfollow rig lists conformance oracle --browser=chromium` green; Firefox once.
- `rigging-follow-path`: `at` 0 / 0.25 / 1 and animated, orient on/off, offset, an open and a closed
  path (wrap), a transformed path; positions within 1e-6 of independently computed values (straight
  and circular paths give closed-form expectations).
- `rigging-list-follow-path`: 1, 3 and 5 children; start/end/shift; a `repeat` whose item count
  changes through data.
- Oracle probes vs Rive's follow-path; for the list row, if a native list scene isn't expressible with
  the local CLI, write a skip note with the evidence. If Rive's spacing or wrap rule differs from D19,
  change the spec and code to match and report it as a deviation.
- `node tools/size.ts` exit 0 with `pathfollow` ≤ 1,280 B, core+web unchanged.

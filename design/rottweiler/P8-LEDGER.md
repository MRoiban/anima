# P8 Rottweiler ledger

Phase P8 (rigging, plus carry-overs), branch `p8-rigging` against `origin/main` (97b509f3). Review
scope: the runtime and tooling source in `design/rottweiler/P8-SCOPE.txt`, with tests, docs, oracle
fixtures, probes and generated wiring excluded. One reviewer per round, on Codex Web (GPT-5.6 Sol
Web, medium; owner's provider rule). The orchestrator verifies each finding, then either fixes it
with the smallest change plus a regression test, or pushes back with the reason.

| id | severity | finding | outcome |
| --- | --- | --- | --- |
| O-1 | major | Found by the full check (`module-order.test.ts`), not the reviewer: P8 modules patched `Player` in an arrival-order-dependent way. | R1-1 | major | Round 1: IK threw `Cannot read properties of null` when a chain bone's world frame collapsed (e.g. an ancestor's scale animated to 0): `invert()` returned null and was dereferenced. | fixed: the IK solve skips a chain with a singular frame and keeps its pose. Regression: `modules/ik/test/core/solver.test.ts` (collapse to zero scale) |
| R1-2 | major | Round 1: scroll treated an offset as driven whenever any timeline in the document targeted it, so a dormant timeline (no state plays it) disabled drag and wheel scrolling. | fixed: an offset is driven only while `Player.writes()` lists it (current layer writes, fading writes, bindings). | R1-4 | minor | Round 1: `copyTransform` accepted `limitSpace` and ignored it; the spec lists only `fromSpace`/`toSpace` for it. | fixed: `limitSpace` is part of the component-copy shapes only, so `copyTransform` reports `unknown-key`. Regression: `modules/rig/test/core/diagnostics.test.ts` |
| R2-1 | major | Round 2: the R1-1 guard was incomplete. Closed after the default three rounds. Round 3's only finding (R3-1) was a tightening of the same IK
inversion path that R1-1 and R2-1 hardened; with it fixed, every IK inversion is finite-checked
before any world frame is written. Usage was not reported by the reviewer runs.

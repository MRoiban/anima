- Merging agent branches: WORKLOG conflicts → keep ours Now, union Log lines; corpus count in `packages/markup/test/corpus.test.ts` = base + each side's delta (check `ls spec/conformance/*/case.ani | wc -l`); oracle `cases.json`/`metrics.json` → union by name; appended SPEC/LOG sections → keep both — merges of BF-1/BF-4/P6-3.

- Perf A/B: in-process against a detached main worktree (`/data/t3/projects/anima-perfbase`) under `taskset -c 5`, alternate order, take minimums — P3b/P3c perf entries.
- Remove every agent worktree after merging (`git worktree remove --force`, delete the branch); kept worktrees filled the root disk — 2026-11-06 disk-full incident (88 worktrees, 12 GB).
- Agent reports of many failures are often load timeouts: P6-2 reported 24 → 859/859 on my rerun at load ~10 (bb12367).
- WORKLOG merge: add only their lines that are not in the merge base (`git show :1:WORKLOG.md`); a plain union re-adds Log lines condensed on ours — BF-3 merge re-added 259.
- Loader hooks (`Icon.loadAssets`) chain: each wrapper must return the previous loader's per-player initializer, or assetio catalogs are lost when fonts loads later — BF-3 × P6-3 merge.
- Budget headroom after P6-4a/P6-4: text 6,142/6,144, markup-libraries 2,173/2,176, markup-hooks 4,488/4,544 — any growth there needs a split first — node tools/size.ts at 23:25.

# P8-9 painted-bounds disposition

See [the explicit oracle skip](../../../tests/oracle/a11y-tree-bounds/skip.json) and
[the existing linear native control](../../../tests/oracle/p7-8-semantic-bounds/README.md).
The native rectangle omits stroke; comparing it to Anima's painted support would test two different
contracts. No new native capture, changed finding, pixel threshold or oracle budget is used.

D32 closes dash bounds as a conservative undashed superset (including effect-stack input contours)
and text as logical line boxes, as DOM rectangles and screen-reader highlights report. P6's
[font-metric observation](text/README.md) remains valid: tool metrics include half a line gap;
browser metrics do not supply a separate line gap. P8 changes neither measurer.

Eight independent conformance probes supply arithmetic expectations for clips, masks, both contour
trim modes and wrap, fixed strokes, feather, dash and text. The fixed-stroke host-size vectors are
also consumed by the pure test; actual settled-host resize and all new overlays are checked in
Chromium and Firefox. Headless tooling and the overlay share the same calculator.

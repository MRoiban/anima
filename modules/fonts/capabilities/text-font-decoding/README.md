# text-font-decoding

The optional fonts-info API is normative in modules/fonts/INFO.md. Original-font API vectors
and authored option projections are in spec/conformance/text-font-decoding. Core diagnostic tests
and both-engine metadata/derived outline tests are in modules/fonts/test/. The native headless
observation boundary is evidenced by tests/oracle/text-font-decoding/skip.json.
No new authoring spellings are needed: font assets, axes and features use their existing registry.

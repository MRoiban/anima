# Machine

Optional state-machine extensions behind `requires: ["machine"]`; normative behavior is
in the machine chapter of `spec/SPEC.md`. `REPORT.md` records verification and costs.

The module extends the existing playback-policy seam. It introduces no renderer operations,
DOM logic or runtime dependencies. Data-sourced numeric blends compile bind expressions until
P4e. Focus supplies `Player.machineFocus(nodeId)` and wakes `onChange` on ownership changes.

State/transition attributes use the generic registry-driven AniML extension, which also
supports module fields on layers, timelines and listeners (MODULES §3). No custom markup hook.

`test/generate.py` writes independently calculated conformance vectors; it never samples
the player. `test/capture.py` independently authors native probes and invokes only the local
headless command runner; generated binaries are deleted without reading them.

## Design decisions and deviations

- JSON and AniML use the existing ease names, e.g. `0.25 out`, rather than the design example's
  illustrative `ease-out`. All §5 weight eases and motion's two elastic extensions are supported;
  value curves stay timeline-only. Settings are static; zero disables inheritance for that box.
- Constrained `measureText` probes do not replace text's drawing cache. The layout adapter remeasures
  after allocation, propagates wrapped hug heights until stable (bounded by node count plus one), and
  supplies the same width to neutral text drawing. This stays entirely in layout-owned files.
- Root overrides consume grid units at P7-3's one CSS pixel/unit convention; no new scaling API.
- `layoutBox`/guards retain targets; `drawnLayoutBox`, local/world translations and neutral drawing
  expose the current drawing. A per-player optional step/busy wrapper keeps the scheduler awake,
  without growing or editing base Player/web code.
- The standard oracle harness is square/static; host-only fit conformance uses both-engine native
  byte comparisons at actual host sizes. Its skip note describes this harness limit and the evidence.
- No native algorithm was copied. Decisions follow the repository's update/feedback and renderer
  comparison research. The reflow timing difference is kept explicit, not hidden with antialiasing.

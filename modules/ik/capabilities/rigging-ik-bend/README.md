# IK bend direction

Implemented by the `bend` field on the registered IK constraint. The normative contract is the
`IK bend direction` subsection of `spec/SPEC.md`; cw/ccw, three target directions and a mirrored
ancestor are covered by `spec/conformance/rigging-ik-bend/`.

The interactive `modules/ik/examples/reach.animl` uses the default cw side. Native oracle evidence
remains orchestrator-owned until its raw comparison is promoted into `tests/oracle/cases.json`.

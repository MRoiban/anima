# Generated font fixture

`anima-test.ttf` is generated by `node tools/test-font.ts`. It contains original geometric
rectangles, metrics, a legacy AV kerning pair, a `wght` axis and a named Bold instance with
`gvar` deltas. It is a test instrument, not a font intended for reading prose. All printable
ASCII, À/É/é, Hebrew א/ב, Arabic ا/ب and a supplementary-plane code point have glyphs.

The generator fixes all timestamps, table order, padding and checksums. The test checks exact
bytes against this committed fixture. No third-party font data is used. Other container and
CFF/GPOS fixtures are constructed in memory by the tests from original data.
